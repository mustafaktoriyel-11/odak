# Vektör harita
Kaynak: Natural Earth 50m (kamu malı) — github.com/nvkelso/natural-earth-vector/geojson. İzdüşüm: Gall stereografik, eski Gemini haritasına oturtuldu (proj.json). Üret: geojsonları indir, python3 uret.py → veri/izinde/harita.svg. Stil: css/uygulama.css sonundaki .iz-taban kuralları.
2,5B derinlik (kıyı duvarı, kayık gölge, ışıklı dağlar, derinleşen deniz): uret.py ve ek_adlar.py'den sonra python3 tasarim/harita/derinlik.py çalıştır.
