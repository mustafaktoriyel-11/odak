# Durak müzikleri
Özgün besteler (MIDI → FluidR3_GM, MIT lisanslı soundfont). Üret: python3 temalar.py; misir.py, cin.py ayrı. Sonra RMS -22 dBFS normalize, AAC 72k → ses/tema/<ad>.m4a. Durak→tema: veri/izinde/rota.json "muzik".
- seyyah.py → ses/tema/seyyah.m4a: harita teması (D dorian, ortaçağ esintili; yaylı ped + arp + blok flüt + hafif def; 16 ölçü, 66 bpm ≈ 58 sn dikişsiz döngü). Haritada 'Müzik' düğmesiyle, kısık (0,3) çalar.
